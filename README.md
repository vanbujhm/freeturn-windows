# FreeTurn для Windows

Полная версия клиента FreeTurn для Windows. Программа принимает ссылку `freeturn://`, которую вам прислали, и одной кнопкой поднимает туннель. Отдельный WireGuard или Amnezia не нужны: туннель, служба и правила сети входят в установщик.

Рядом живёт лайт-версия `freeturn-lite-windows`. Режим `mode: tcp` поддерживает только она: профиль с таким режимом полная версия отклоняет.

## Требования

- Windows 10 версии 1809 (сборка 17763) или новее, Windows 11. Только 64-разрядная.
- Права администратора при установке и удалении. Работает программа от обычного пользователя, туннель держит служба `FreeTurnService`.
- WebView2 Runtime. В Windows 11 и в обновлённой Windows 10 он уже есть, если нет, установщик запустит загрузчик Microsoft, для него нужен доступ в интернет.

## Установка

1. Запустите `FreeTurnSetup-<версия>.exe` и подтвердите запрос на права администратора.
2. Каталог установки выбрать нельзя: программа ставится в `C:\Program Files\FreeTurn`. Служба держит данные в `C:\Program Files\FreeTurn\Data`, и этот путь она вычисляет сама.
3. Устанавливайте программу из учётной записи, под которой будете ею пользоваться: профили и автозапуск хранятся в профиле этого пользователя.
4. Обновление это установка поверх прежней. Профили и настройки сохраняются.
5. Откройте ссылку `freeturn://` из мессенджера или вставьте её в окне программы, потом нажмите «Подключить».

Удаление через «Параметры, Приложения» останавливает и удаляет службу, адаптер, схему `freeturn://`, автозапуск и каталог `Data`. Про профили с ключами в `%LOCALAPPDATA%\FreeTurn` установщик спросит отдельно. Ответ «Да» стоит по умолчанию.

## Windows пишет «Windows защитила ваш компьютер» (SmartScreen)

Установщик не подписан сертификатом издателя, поэтому SmartScreen предупреждает о нём при первом запуске. Это не значит, что файл заражён, система просто не знает издателя.

1. В окне предупреждения нажмите «Подробнее».
2. Появится кнопка «Выполнить в любом случае», нажмите её.

Скачивайте установщик только у того, кто вам его прислал, и сверьте с ним хэш SHA-256, если он его сообщил:

```powershell
Get-FileHash .\FreeTurnSetup-0.9.0.exe -Algorithm SHA256
```

## Антивирус ругается или удаляет файл

Программа управляет сетью: создаёт адаптер, меняет маршруты и правила брандмауэра. Антивирус может счесть такое поведение подозрительным, особенно у неподписанного файла.

- Если файл удалён или помещён в карантин, верните его оттуда и добавьте `C:\Program Files\FreeTurn` в исключения антивируса.
- Если антивирус блокирует службу или адаптер при подключении, проверьте его журнал блокировок и разрешите `FreeTurnService.exe`.
- Подробности отправьте тому, кто выдал вам ссылку, вместе с названием антивируса.

## Что-то не работает

В окне программы откройте «Журнал» и нажмите «Сохранить диагностику». Файл не содержит ключей и ссылок. Отправьте его тому, кто вам помогает, и опишите, что вы делали и что увидели.

## Сборка

Нужны Go 1.26.10, Node, Wails v3 CLI (`wails3`) и Inno Setup 7. Сборку целиком делает скрипт `build.ps1`:

```powershell
pwsh -File build.ps1 [-Version 0.9.0] [-UpdateRepo владелец/репозиторий] [-Iscc путь\к\ISCC.exe] [-SkipInstaller]
```

Скрипт проверяет `wintun.dll` по хэшу и подписи, собирает интерфейс и оба exe с `CGO_ENABLED=0` в `build\` и затем установщик в `dist\`. Ключ `-SkipInstaller` останавливает его после exe, Inno Setup для этого не нужен. Тесты запускает `test.ps1`.
