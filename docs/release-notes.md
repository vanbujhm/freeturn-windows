# Заметки к версиям

## Следующая версия

- **Правило для сайта действует и для поддоменов.** Правило `example.com` теперь включает `www.example.com`, `mail.example.com` и любой другой поддомен. Это касается и правил, добавленных раньше. Во время подключения FreeTurn сам отвечает системе на DNS-запросы и успевает поставить маршрут до первого соединения с новым поддоменом.
- **Вкладка «Запросы».** Показывает, какие имена спрашивали программы, какие адреса пришли, пойдёт трафик через VPN или напрямую и какое правило сработало. Из строки можно сразу добавить правило. Журнал хранится только в памяти службы: на диск и в диагностику он не попадает.
- **Программы только через VPN.** На экране маршрутизации можно выбрать программы, которые во время подключения выходят в сеть только через VPN, а без VPN остаются без сети.
- **Продвинутое решение капчи.** Новая настройка, как в Android-клиенте: ядро решает капчу VK новым способом, через настоящую страницу капчи. По умолчанию выключена, для профилей с ручным вводом капчи не действует.
- **Ядро free-turn-proxy 4.1.4.** Закрыта уязвимость CVE-2026-98432, обновлены зависимости, исправлен запасной путь продвинутой капчи.
- Безопасный DNS (DoH) в браузере идёт мимо FreeTurn: для браузера с DoH правила для сайтов не действуют. Экран маршрутизации предупреждает об этом.
